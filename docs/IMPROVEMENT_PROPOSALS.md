# 改善案 TOP3

## 1. セーブ/ロード機能の追加 【優先度: 高】

### 現状
- プレイデータ（ゴールド・討伐数・武器・仲間・スキルの所持状況）がすべてメモリ上のみ
- リロードやタブを閉じると進行がすべて消える
- 放置系ゲームとして「続きからプレイ」ができない

### 改善案
- **localStorage でオートセーブ**: 一定間隔（例: 10秒ごと）または状態変更時に `gold`, `enemyKills`, `weapons`, `companions`, `skills` を JSON で保存
- **起動時に復元**: `useEffect` でマウント時に localStorage を読み、存在すれば state の初期値として反映
- **「リセット」ボタン**: セーブを削除して最初からやり直せるようにする（任意）

### 実装のポイント
- セーブデータにバージョン番号を持たせ、将来フォーマット変更時にマイグレーション可能にする
- 即死スキルなどで `currentEnemy` だけは復元しない（次の敵を `generateEnemy(enemyKills)` で再生成）

---

## 2. コンポーネント・ロジックの分割 【優先度: 中】

### 現状
- `app/page.tsx` が 800 行超で、ゲームロジック・UI・データ定義が1ファイルに集中
- 修正や機能追加のたびに同じファイルを触るため、競合や見落としが起きやすい
- 単体テストや再利用がしづらい

### 改善案
- **カスタムフック `useGameState`**: `gold`, `enemyKills`, `currentEnemy`, 武器・仲間・スキルの state と、`attack` / `buyWeapon` / `buyCompanion` / `useSkill` / `generateEnemy` などを集約
- **UI コンポーネント分割**:
  - `EnemyDisplay` … 敵画像・HPバー・攻撃ボタン・ダメージポップ
  - `StatusCard` … ゴールド・討伐数・DPS・ステージ情報
  - `WeaponPanel` / `CompanionPanel` / `SkillPanel` … 各ショップ/スキル一覧
- **定数・データの分離**: 武器リスト・仲間リスト・スキルリスト・敵テンプレートを `lib/game-data.ts` などに切り出し

### 実装のポイント
- まずは「データの切り出し」と「1つだけ子コンポーネント化」から始め、段階的に分割すると安全
- `page.tsx` はレイアウトと `useGameState()` の呼び出しに絞る

## 3. バフ残り時間の表示 ＋ 武器バランスの修正 【優先度: 高】

### 現状
- **バフ**: クールタイムは「CD ○秒」で表示されるが、発動中のダメージ/攻撃速度/ゴールドバフの「あと何秒で切れるか」は表示されていない
- **武器**: 鋼鉄の剣（id:4）のダメージが 120 で、鉄の剣（id:3）の 250 より低く、成長曲線が逆転している

### 改善案
- **バフ残り時間**:
  - 各バフの「終了時刻」（`Date.now() + durationSeconds * 1000`）を ref または state で保持
  - 1秒ごとのタイマー（既存のクールタイム用と共通化可能）で「現在時刻と終了時刻の差」を計算し、画面上に「攻撃力2倍 残り15秒」のように表示
- **武器バランス**:
  - 鋼鉄の剣のダメージを 120 → 500 前後に修正し、鉄の剣（250）より強くする

### 実装のポイント
- バフ残り表示は、ステージ情報カードの近くか、戦闘エリアの上にコンパクトなバッジで出すと視認しやすい
